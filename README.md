★ : 관리자 로그인 필요 표시
main은 SWING화면, main2는 콘솔창입니다.

0. 메인 화면 
- 왼쪽 버튼을 통해 선택
- product, order, orderItem, purchase, admin, store, 종료 순서
- 관리자 로그인 필요한 기능에는 관리자 로그인 확인

1. Admin(관리자, 로그인)
- 로그인(id, pw)
- 관리자 등록★
- 조회★
- 로그아웃

● 로그인이 풀리지 않는지, 재로그인 시 잘 작동하는지 확인
● 관리자 등록이 잘 되는지 확인
● 조회가 잘 되는지 확인
● 로그아웃이 잘 되는지 확인


2. Purchase(발주, CRUD) ★
- 전체 조회
- 상품id로 조회
- 신청(product 재고 추가) 
- 취소(신청 시 추가한 것만큼 감소) 
- 수량 변경(재고 수량 변경)

● 발주 신청 시 product 의 재고가 증가하는지 확인
● 발주 취소 시 product 의 재고가 감소하는지 확인
● 발주 수량 차감 시 product 의 재고가 감소하는지 확인
● 조회 확인


3. Product(상품, CRUD) ★
- 추가
- 상품명만 조회 
- 수정
- 삭제
- 전체 조회
- 상품명으로 검색
- 상품id로 검색
- 재고 부족(재고가 10개 이하인 상품)

● 상품이 추가되는지 확인
● 상품 수정 시 내용이 바뀌는지 확인
● 상품 삭제 시 삭제되는지 확인
● 조회 확인
● 재고 부족 확인(10개 이하인 제품)


4. Order(주문/결제)
- 주문 결제(장바구니 기능으로 0을 누르기 전까지 추가 가능 - 재고 차감)+ orderItem와 정보 연결			
- 주문 조회 (orderItem의 수량 변경, 취소 시 총 금액 변경됨) 
- 주문 상세 조회(주문 한 것 상세보기 + orderItem 의 수량 변경, 취소 시 상세 내역 변경됨)
- 주문 수정▶ 주문 수정은 콘솔창에서만 현재 가능
- 주문 취소(주문 한 것만큼 재고 증가 + orderItem에서 삭제)

● 주문 결제 시 product에서 재고가 차감되고, orderItem에는 주문이 들어가는지 확인
● 주문 취소 시 product에서 재고가 증가하고, orderItem에서 주문이 취소되는지 확인
● 주문 수정(콘솔한정) 주문 수정되는지 확인. product와 orderItem에서 재고 변경되는지 확인
● 주문 조회 확인


5. OrderItem(주문CRUD)
- 특정 주문 조회(orderId)
- 전체 조회
- 수량 수정(재고 수량 변경, order 가격, 상세 내역 변경)
- 상품 삭제(재고 수량 변경, order 가격, 상세 내역 변경)
- 주문 총액 

● 주문 수정 시 order에서 총액과 상세 조회 시 수량이 변경되는지 확인, product 재고 변경이 되는지 확인
● 주문 취소 시 order에서 총액과 상세 조회 시 주문이 없어지는지 확인, product 재고가 증가 되는지 확인
● 주문 조회 확인


6. Store(매장 정보) 
- 매장 전체 조회
- 지역별 매장 조회

● 매장 조회 확인
